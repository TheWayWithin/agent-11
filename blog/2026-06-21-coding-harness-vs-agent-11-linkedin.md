How do you trust AI-written code you didn't read line by line?

An AI agent writes a few hundred lines in minutes. It runs, the tests are green. Shipping without reading all of it still feels like a leap.

After months of building this way, my answer: you can't trust the model. You trust the process around it. Most AI tools give you a thin wrapper and trust the model completely. That's the one thing you can't afford to do.

So the checks that grade the work can't be edited by the agent doing the work.

"Done" means real command output, not "looks right".

Review is split: one agent finds the problems, a different one fixes them, so nothing marks its own homework.

As the models get better at writing code, "can it write it" stops being the question. "Can I trust it without reading every line" is what's left. That's process, not model.
